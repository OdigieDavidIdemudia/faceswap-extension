# Google Colab GPU Server Setup

Follow these steps to get a high-speed AI server running for free on Google Colab.

### 1. Open Google Colab
Go to [colab.research.google.com](https://colab.research.google.com/) and create a **New Notebook**.

### 2. Enable GPU
- Go to **Edit** > **Notebook settings**.
- Select **T4 GPU** (or any available GPU) under "Hardware accelerator".
- Click **Save**.

### 3. Run the Setup Code
Copy and paste this **ENTIRE** block into a single cell and run it:

```python
# 1. Install Dependencies
!pip install pyngrok fastapi uvicorn[standard] python-multipart pillow insightface==0.7.3 opencv-python onnxruntime-gpu requests pyvirtualcam

# 2. Start Tunnel (Requires ngrok token)
from pyngrok import ngrok
# Replace 'YOUR_AUTHTOKEN' with your token from ngrok.com
AUTHTOKEN = "YOUR_AUTHTOKEN"
!ngrok authtoken {AUTHTOKEN}

public_url = ngrok.connect(8000).public_url
print(f"\\nYour Public Server URL: {public_url}\\n")

# 3. Start Server (Assuming you uploaded server.py already)
!python server.py --host 0.0.0.0 --port 8000
```

### 4. Connect the Extension/Web App
1. Copy the **Public Server URL** generated by the code (e.g., `https://random-id.ngrok-free.app`).
2. Paste it into the new **"Server URL"** field in your FaceSwap Extension or Mobile Web App.
3. Click **"Save"** or **"Use"**.
4. The status dot should turn **Green**, and you'll get nearly 20-30 FPS!

# Future Upgrade: Hardware Guide (Local Focus)

When you are ready to move away from the cloud and run this smoothly on a laptop, look for these specs:

1. **GPU (Most Important)**: Must be an **NVIDIA GeForce RTX** card.
   - **Minimum**: RTX 3050 (4GB VRAM)
   - **Recommended**: RTX 4060 or better (8GB+ VRAM)
   - *Note: Avoid AMD (Radeon) or Intel (Arc/Iris) for this specific AI software, as it relies heavily on NVIDIA CUDA.*

2. **RAM**:
   - **Minimum**: 16GB
   - **Recommended**: 32GB

3. **Processor (CPU)**:
   - **Minimum**: Intel Core i7 or AMD Ryzen 7 (12th Gen or newer)

**With an RTX 4060 laptop, you will get 30+ FPS locally without any cloud setup!**
